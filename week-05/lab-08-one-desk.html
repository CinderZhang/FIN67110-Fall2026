Lab 08 — One Desk

One thing today: join your agent team and your skills into one desk that runs with one command, with the hook on every output. (45 minutes, after the teaching.)

You arrive with: your agent team running on a ticker; the seeker, the worksheet and the hook; your hand drawing of the desk with one arrow per file; one line on which join you will use for the worksheet.

Open — the paired review (10 minutes)

  1. Tools alive. The team runs on a ticker; the seeker's last report exists; the hook refuses the seeded copy from Lab 07.
  2. Defend. Show your partner your drawing. Partner asks: which arrow is a file, and which is a call?
  3. Gap check. Write the order the parts run in, from memory. If a model decides any step of it, that is today's gap.

D — the question, the same for everyone

Can one command run the team and the skills in an order code fixes, through one run folder, with every number still traced and the hook still able to refuse?

I — build it from the contract

Here is the contract for the joined desk. It states what the desk must do and what it must never do. You own the design: choose which join to use, lay out the run folder, and name the command. Send the request as written or in your own words, and keep every sentence that says "never."

  1. Send your coding agent the request:

Join my agent team and my skills into one desk that runs with one command, and put it behind the page from Lab 05. The command takes a ticker, or the word "screen" to take the top name from my seeker's latest report. It runs the parts in an order fixed in code, never chosen by a model: the seeker when asked, the pick, the agent team on the ticker, the worksheet skill on the team's saved run, and the hook on every output. Every part reads from and writes into one run folder, named by the ticker and the date and time the command started, and no part fetches a filing another part already saved. Where a role uses a skill's output, it receives the output as a file; it may quote the file's lines and may never recompute them. The final report is the team's verified report with the worksheet's view under it, and its first line names every filing any part read. Each part prints the seconds it took on its last line. When the ticker is not in the seeker's registry, the spinoff parts print "not applicable" and the rest runs. When any part fails, the command stops, prints which part failed and the error, and keeps the run folder. The hook runs on the final report as it runs on a skill's output. The page runs this command and shows the final report. Nothing in the code names a company. Tell me the exact command to run the desk on a ticker, the exact command to run it from the screen, and the exact command to replay a saved run without fetching anything.

Rewrite it in ASD-STE100 yourself before you send it, as Week 1 taught; a sample is here.

  1. Run the desk on the name your worksheet ran on in Lab 07. Expect: one run folder; each part's output in it; the final report with the view under it and the filings on its first line; the seconds per part. Then run it from the screen. Expect: the top name of the seeker's report, or "not applicable" on the spinoff parts if the screen is empty.
  2. Replay the saved run with the network off. Expect: the same final report, and no fetch.
  3. Copy the final report, change one amount by one, and run the hook on the copy. Expect: a refusal that names the line. The shape, not your answer: refused: line 14, [amount] is not in [filing], [section].
  4. While it runs: work one item from your gap list in a second AI chat. Never collected.
  5. Something not working? Debug with your AI: paste the exact command and the exact error text.

Orchestration — Learn on your own

  1. What is it (code that fixes the order in which parts run, and a model that chooses none of it)?
  2. How does it work here (which lines of your command are the order, and what would a model choosing the order have cost you on the replay)?
  3. Explain it: open your agent's page on subagents. What does it hand to a subagent and what does it get back, and where is the run folder in that picture?

Reflect

Explain two things to your partner. First, name the join you chose for the worksheet, and read the one sentence in a role's instructions that stops it from recomputing. Second, name the part you would cut if the client gave you half the time.

Before Session 9 — do these: complete the list on the Week 5 page, which takes about 30 minutes.
