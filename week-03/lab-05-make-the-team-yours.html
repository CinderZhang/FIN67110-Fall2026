Lab 05 — Make the Agent Team Yours

One thing today: give each analyst role a persona you wrote that must draw an insight, prove the team on a company your partner picks, file Checkpoint 2, and form your team.

You arrive with: Tuesday's agent team running with the verifier, the seeded-error marks saved and pushed, your three persona drafts from the Week 3 list.

Open — the paired review (10 minutes)

  1. Tools alive. The agent team runs on COST; the seeded-error marks open; your AI agent answers.
  2. Defend. Show your partner the node order printed by two runs. Partner asks: what would the verifier do with a number that is in the release but belongs to a different quarter?
  3. Gap check. Write one line: the one claim in your Costco report that the release's first paragraph does not state. If every claim restates it, that is today's gap.

D — the question, the same for everyone

With the process fixed, can each role's work be yours: a persona that reads the filings its own way and states one claim the headline does not, and does the agent team hold up, verified, on a company you did not choose?

R — what you work from

Input Where

A company you did not choose your partner picks it: any U.S. company that reported this month. Start here: EDGAR full-text search; the agent team takes its ticker

I — make it yours

  1. Write the personas yourself. For each of the three analyst roles (the Manager keeps its checklist), rewrite the role's instruction file in your own words, in the six parts: identity; how it reads a company; what it is given; the criteria it scores, each with a number and its source; what would change its view; the output, ending with one line that begins "Insight:" and states a claim the filings support and the release's first paragraph does not, with the line it came from. No AI writes a persona: this is the part of the desk that is yours. Twenty minutes.
  2. Send your AI coding agent this request word for word:

In my agent team, I want each analyst role's output to end with one line that begins "Insight:" and states one claim, with the filing and the line it comes from. Add two checks to the Strategy Manager: a part fails if it has no Insight line, and a part fails if its Insight line only restates a figure that the earnings release's first paragraph already states. Send a failing part back to its role one time only, as now. The Verifier checks the number in each Insight line like every other sourced number. Do not change the graph's order. Nothing in the code names a company. Tell me the exact command to run the agent team.

Rewrite it in ASD-STE100 yourself before you send it, as Week 1 taught; a sample is here.

  1. Run it on COST with the same peers and price as Tuesday. Expect: three Insight lines in the verified report, each with a mark; the node order unchanged.
  2. The partner's pick. Your partner names the company. Run the agent team on its ticker, with peers you choose. Expect: a verified five-part report about that company, every number with its source, three Insight lines, the table of marks. Not running with twenty minutes left? The fallback produces a report; Checkpoint 2 needs Tuesday's marks, which you already have.
  3. Wrap it in a UI. The logic is done; now a person who never opens a terminal must be able to run it. Send your agent:

Put a user interface on my agent team: a page where a person types a ticker, optional peers and a price, presses run, watches each node's name appear as it runs, and reads the verified report with its marks when it ends, without opening a terminal. Keep every command working as it is. Tell me the exact command to start the page.

Rewrite it in ASD-STE100 yourself before you send it, as Week 1 taught; a sample is here. Expect: your partner runs the agent team on their pick from the page, and reads the verified report there. From here on, each new piece of the desk goes behind this page. 6. While it runs: work one item from your gap list in a second AI chat. Never collected.

Teams — form now

Three students. Write the three names and one team name on paper and show the instructor before the end of class. Anyone unplaced at the end of class is placed by the instructor.

Persona, not prompt — Learn on your own

  1. What is it (an instruction file that fixes what a role values, what it is given and what it must return; the model fills it differently on every run)?
  2. How does it work here (which part of your persona the verifier can check, and which part only a reader can judge)?
  3. Explain it: open the first screen of FAskills, where seven investor personas each score one stock. What does a persona that scores add that a role that describes lacks?

Reflect

Explain to your partner: 1. the Insight line you would trust least, and why; 2. which member's agent team your team starts from, and what it lacks.

Checkout — Checkpoint 2

By the end of the day (the schedule), in Brightspace → Checkpoint 2: a permalink (commit link) to your repository holding the agent team, with the verifier's marks on the seeded-error test.
