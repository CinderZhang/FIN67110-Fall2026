Lab 04 — the agent team as a graph in code

Rebuild my desk as an agent team in Python with [LangGraph, the OpenAI Agents SDK, PydanticAI or CrewAI Flows]. Keep my seven steps as the team's tools. Keep my four roles' instructions; put each role's instructions in its own file in a folder named roles. The process is a graph in code. The graph has these nodes, in this order: the steps; the Research Analyst; the Financial Analyst; the Investment Advisor; the Strategy Manager; the Verifier. The order is the same on every run. A model never decides which node runs next. Each role node is one model call with the instructions from its file. Each role node receives only the state the graph gives it, as JSON: the task, the context and the expected output. The Manager checks that the five parts are present and consistent (Overview; Market Positioning and Growth Outlook; Valuation Insights; Future Developments and Strategic Recommendations; Investment Recommendation). If a part fails, the Manager sends that part back to its role one time only. Then the Manager compiles the report. No role runs more than two times in one run. The Verifier runs after the Manager, on every run. No option turns it off. It receives only the compiled report, the saved filing texts and the saved facts. It skips the Investment Advisor's thesis. For every other sourced number it checks, in code: a number sourced to an XBRL tag and period, against the facts file, exactly; a number sourced to a line, that the line appears in that filing's text, allowing for spacing and formatting differences; a ratio, by recomputing it from its quoted inputs. Then, with the model, it checks that the line states that number for that period in that definition. A number with no source is unsupported. A ratio with no definition, where the filing offers two, is unsupported. The Verifier marks each number correct, wrong or unsupported. It corrects wrong and unsupported numbers from the filings, with the real line or tag beside each. Every run saves, in its own folder named by company, date and time, never overwriting an earlier run: the filing texts, the facts, each node's input and output, the report, and the verified report with the table of marks under the first line. The first line stays the filings line. The program takes a ticker, an optional --peers list of tickers, an optional --price number, and an optional --verify-only path to a saved run. With --verify-only it runs the Verifier on that run and nothing else. Print each node's name as it starts. Nothing in the code names a company. Read my key as API_KEY from .env. Tell me the exact command to install the packages, the exact command to run the agent team on a ticker with peers and a price, and the exact command to verify a saved run.

Lab 05 — the Insight line

In my agent team, each analyst role's output must end with one line that begins "Insight:" and states one claim, with the filing and the line it comes from. Add two checks to the Strategy Manager: a part fails if it has no Insight line; a part fails if its Insight line only restates a figure that the earnings release's first paragraph states. Send a failing part back to its role one time only, as now. The Verifier checks the number in each Insight line like every other sourced number. Do not change the graph's order. Nothing in the code names a company. Tell me the exact command to run the agent team.

Lab 05 — the UI

Add a user interface to my agent team. It is a page. A person types a ticker, optional peers and a price, and presses run. The page shows each node's name as it runs. When the run ends, the page shows the verified report with its marks. The person does not open a terminal. Every command keeps working as it is. Tell me the exact command to start the page.
