I — prove each item to your partner

You show, your partner watches, then you switch. Keep the order: a failing item blocks the ones after it.

  1. Python. python --version (on Windows, py --version if python is not found). Expect: 3.11 or higher.
  2. The agent writes a file. In your agent, in your work folder, send: "Create a file named hello.md containing today's date and the name of the model you are." Expect: hello.md appears in the folder; open it. An agent that answers in chat but creates no file is not running in this folder.
  3. The agent writes so you can check it. In each agent, send: "Add this line to the instruction file you read at the start of every session in this folder, creating the file if there is none, and tell me its name: When you explain something to me, write 80% of the way to ASD-STE100, and keep every number, condition and hedge." Then ask it what a .gitignore file does. Expect: the file it named is in the folder, and the answer comes in short sentences, one claim each. Why: the Week 1 page.
  4. The key and the fence. Send your agent word for word, filling the brackets:

Create a .env file in this folder with two placeholder lines, API_KEY=paste-here and SEC_USER_AGENT="[your name] [your Purdue email]", and a .gitignore that excludes .env. Then write a short Python program, check_env.py, that loads .env, prints the first four characters of API_KEY followed by "...", and prints SEC_USER_AGENT. Tell me the exact command to install any package it needs and the exact command to run it.

Open .env (in a terminal in your work folder, notepad .env on Windows or open -e .env on a Mac), paste your model provider's key where your agent said, and save it under the same name, never .env.txt. Run the install command, then the run command. Expect: four characters of your key, three dots, then your User-Agent. This proves the file is read, not that the key works: Session 3 makes the first paid call. 5. GitHub. Expect: check_env.py and hello.md are there and .env is not. The repository is public, so this check is the one that keeps your key yours. 6.
